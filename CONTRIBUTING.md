# Contributing

Thank you for contributing to the FACTA SDK.

## Requirements

- Node.js >= 18
- npm or yarn

## Setup

```bash
git clone https://github.com/factacorp/factacorp-sdk.git
cd factacorp-sdk
npm install
```

## Building

```bash
npm run build
```

Compiled files and TypeScript declarations are output to `./dist`.

## Workflow

1. Fork the repository and create your feature branch from `main`.
2. Verify that the build succeeds without errors: `npm run build`.
3. Never commit private keys, secrets, API tokens, or personal identifiers.
4. Open a pull request against `main` with a clear explanation of your change.
